# Smart Wallet System

A secure and modular console-based digital wallet application built in Java.

## Features
- **Encapsulation:** Safe balance protection using private fields.
- **Input Validation:** Robust error handling that prevents application crashes on invalid user input.
- **Menu-Driven Interface:** Interactive loop allowing users to check balances, deposit, and withdraw funds seamlessly.

## Getting Started

### Prerequisites
Make sure you have Java installed on your computer.

### How to Run
1. Open the project folder in your terminal or IDE.
2. Compile the Java file:
   ```bash
   javac Main.java
